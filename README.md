This portfolio demonstrates practical Python tools for Critical Infrastructure Operations, SOC monitoring, and IT automation.



\## 🔧 Projects Included



\### 1. api\_checker.py - API Uptime Monitor

\- Checks API health (200, 401, 404, 500)

\- Logs with timestamp for audit trail

\- \*Use Case:\* Monitoring SCADA / EMS / grid management APIs



\### 2. account\_lockout\_policy.py - Account Lockout Policy

\- Locks account after 3 failed login attempts

\- Prevents brute-force attack

\- \*Use Case:\* Securing operator logins at transmission stations



\### 3. password\_gen.py - Secure Password Generator

\- Generates strong passwords using ascii + digits + symbols

\- \*Use Case:\* IT hygiene for field engineers



\### 4. scrabble.py / dhee.py / rak.py / number\_con.py

\- Logic, loops and automation exercises showing Python fundamentals



\## 💻 Tech Stack

Python 3.15, requests, datetime, logging, regex
